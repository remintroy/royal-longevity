# Booking banner

Generated with the built-in image generation tool using the owner-supplied banner as a reference. Full-bleed photography replaces the reference's baked-in white frame. Two optimized WebP assets are selected with Next.js getImageProps and a native picture element: portrait below 1024px, landscape from 1024px. Desktop photography is mirrored in RTL because it contains no text or logo. Mobile copy sits above the objects; desktop copy sits in the dark negative space.

## Desktop prompt

Use case: product-mockup. Create a photorealistic premium spa website banner using the supplied image as a visual reference for warm ivory towels, gold-pump ivory lotion bottle, white flowers, marble and soft botanical shadows. Landscape 3:1 composition, 2400x800 if possible. FULL BLEED photograph all the way to every edge: absolutely no white margins, no frame, no border, no rounded corners, no inset picture. Arrange a rolled ivory towel, bottle and white flowers on the RIGHTMOST third, with the towel and objects fully inside the scene. The LEFT 60% is quiet deep warm espresso-brown wall with subtle natural soft light, ample dark negative space for separately rendered ivory HTML heading and button. Lighting transitions naturally, no graphic gradients. Elegant realistic tactile photography matching the reference. No text, no logo, no watermark: leave towel plain rather than inventing brand marks. The website will supply all typography. Keep subject compact within right third, vertical center/lower half so cropping works. Generate only the image, no web mockup.

## Mobile prompt

Use case: product-mockup. Generate a matching MOBILE portrait spa banner photograph, 1024x1536. Match the photograph just generated in this conversation: ivory rolled towel, ivory gold-pump lotion dispenser, white flowers on warm marble with soft botanical shadows, rich warm espresso background. Full bleed photography to all four edges, NO padding, white border, frame, rounded corners, text, logos or watermark. Critical composition: TOP 58 percent is quiet dark espresso wall with only extremely subtle soft shadows, empty for website heading and appointment button rendered later in HTML. Arrange the entire towel, bottle and flowers in BOTTOM 38 percent, with breathing room on both sides; bottle does not extend above bottom half. Premium realistic tactile warm lighting, objects naturally lit, top dark for readable ivory text. This is the vertical companion to a desktop spa banner, no mockup.
