# Introduction image prompts

Tool: built-in image generation, followed by WebP encoding at quality 88.
These are generated demo interiors, not verified photographs of the premises.

Initial compositions used `public/assets/images/introduction-lounge.png` as the
room reference: warm ivory marble reception, cream boucle sofa, bronze marble
coffee table, olive foliage, natural sunlight, no people. Separate 9:16 mobile,
4:5 tablet, and 16:9 desktop compositions were generated with blank walls.
The following final edits used each composition as image 1 and the supplied
Royal Longevity Beauty vertical PNG as image 2. Original branding files were
not modified. The final desktop uses the first branded edit; a later placement
experiment was discarded in favour of a layout safe area.
